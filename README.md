# 🎓 Sunbird Trust - Career Guidance Handbook Web Portal

An interactive, responsive, single-page web portal created for the **Career Guidance Handbook for Students** (Sunbird Trust Educational Initiative).

---

## 🚀 How to Publish on GitHub Pages

Follow these simple steps to host this web portal for free on **GitHub Pages**:

### Option 1: Using Git Terminal (Recommended)

1. **Initialize Git & Commit**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Sunbird Trust Career Handbook Web Portal"
   ```

2. **Create a New Repository on GitHub**:
   - Go to [GitHub.com](https://github.com/new) and create a new public repository (e.g. `career-handbook`).

3. **Push Code to GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/career-handbook.git
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - Go to your repository on GitHub -> **Settings** -> **Pages**.
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch`
     - **Branch**: Select `main` / `/ (root)`
   - Click **Save**.
   - Your live website link will be ready at:
     `https://YOUR-USERNAME.github.io/career-handbook/`

---

## 🌐 How to Embed your GitHub Pages site in Google Sites (Zero Cropping!)

Once your GitHub Pages link is live (e.g. `https://YOUR-USERNAME.github.io/career-handbook/`):

1. Open your **Google Sites Editor**.
2. Click **Insert** -> **Embed** -> **By URL**.
3. Paste your live GitHub Pages link: `https://YOUR-USERNAME.github.io/career-handbook/`
4. Select **Whole Page**.
5. Drag the blue border handles in Google Sites to make it full width!
6. Enjoy a 100% full-bleed, responsive web page on Google Sites!

## 🛠️ Included Webpage Features

- 🎯 **Stage-wise Roadmap**: Interactive breakdown from Primary (Grades 1-5) to Postgraduate level.
- 📝 **National Entrance Examinations**: Filterable database of JEE, NEET, CUET, CLAT, AILET, GATE, CAT, NIFT, NID DAT, IAT, NEST with official links.
- 🏛️ **Government Recruitment Exams**: Comprehensive search for UPSC CSE, SSC CGL/CHSL, IBPS, RBI, Defence (NDA/CDS), Railways (RRB), and CA (ICAI).
- 🎓 **Professional Courses**: Deep dive into B.Tech, MBBS, Law, BBA, BDS, Nursing, Architecture, Design, Agriculture, and BCA.
- 🏫 **Top Universities Directory**: IITs, NITs, IISc, AIIMS, DU, NLUs, IIMs, and NIFT overview.
- 💰 **Scholarships Directory**: Central schemes (NSP, INSPIRE, PM-YASASVI, AICTE) plus **24+ Colleges with Scholarships** (focusing on North-East India).
- 💼 **Career Profiles Matrix**: Doctor, Software Engineer, Civil Servant, CA, Lawyer, Data Scientist with salary ranges & pathways.
- 💡 **Essential Skills Checklist**: Interactive progress bar checklist for student skill building.
- 🌙 **Dark Mode & Search**: Instant theme toggle, global search bar, and print-ready stylesheet.
